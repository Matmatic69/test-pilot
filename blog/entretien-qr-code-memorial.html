Guide d'Entretien Mensuel

Routine d'Entretien Recommandée

Fréquence : 1 fois par mois (lors de votre visite au cimetière)

  1. Inspection visuelle : Vérifiez qu'il n'y a pas de fissures, décollement ou saleté importante
  2. Nettoyage doux : Essuyez avec un chiffon doux légèrement humide (eau claire)
  3. Séchage : Laissez sécher naturellement ou essuyez avec un chiffon sec
  4. Test de scan : Scannez le QR code avec votre smartphone pour vérifier la lisibilité

Temps requis : 2 minutes maximum

À Faire / À Ne Pas Faire

✓ À FAIRE

  • ✓ Nettoyer avec un chiffon doux humide
  • ✓ Utiliser de l'eau claire tiède
  • ✓ Essuyer délicatement en mouvements circulaires
  • ✓ Tester le scan régulièrement
  • ✓ Retirer délicatement les feuilles mortes/débris
  • ✓ Sécher avec un chiffon microfibre si besoin

✗ À NE PAS FAIRE

  • ✗ Utiliser des produits abrasifs (Javel, CIF, etc.)
  • ✗ Gratter avec un objet dur ou une éponge à récurer
  • ✗ Utiliser un nettoyeur haute pression
  • ✗ Appliquer de l'alcool ou des dissolvants
  • ✗ Utiliser des produits acides (vinaigre, citron)
  • ✗ Frotter trop fort (risque de décoller)

Problèmes Courants et Solutions

Problème 1 : Le QR Code Ne Scanne Plus

Causes possibles :

  • Saleté ou poussière recouvrant le code
  • Rayures superficielles
  • Mauvaise luminosité lors du scan

Solutions :

  • ✓ Nettoyez délicatement avec un chiffon doux humide
  • ✓ Essayez de scanner sous différents angles
  • ✓ Améliorez la luminosité (utilisez la lampe du téléphone si nécessaire)
  • ✓ Si le problème persiste, utilisez le 2ème QR code fourni

Problème 2 : Le QR Code Se Décolle Légèrement

Causes : Adhésion insuffisante lors de la pose initiale, ou surface poreuse

Solutions :

  • ✓ Retirez délicatement le QR code
  • ✓ Nettoyez et séchez parfaitement la surface
  • ✓ Installez le 2ème QR code fourni en suivant les instructions
  • ✓ Appuyez fermement pendant 30-60 secondes

Problème 3 : Salissures Tenaces (Mousse, Lichen)

Solutions :

  • ✓ Humidifiez avec de l'eau tiède pendant 2-3 minutes
  • ✓ Frottez délicatement avec un chiffon doux
  • ✓ Rincez à l'eau claire
  • ✓ Si la mousse persiste, utilisez une brosse à dents souple

Optimiser la Durée de Vie

Conseils Pour Maximiser la Longévité

  • 1. Emplacement stratégique : Placez le QR code dans une zone protégée des écoulements d'eau directs
  • 2. Surface adaptée : Privilégiez une surface lisse (marbre poli, granit lisse) plutôt que poreuse

  • 4. Entretien régulier : Un nettoyage mensuel prévient l'accumulation de saleté tenace
  • 5. Test de lisibilité : Scannez le QR code lors de chaque visite pour détecter tout problème
